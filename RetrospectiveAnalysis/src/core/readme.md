# Retrospective Analysis Core

The core retrospective data analysis library.

- [lib.py](./lib.py) basic shared tools for Lorentzian peak fitting, cosine similarity peak tracking and hough transform peak mapping.
- [passive_tools.py](./passive_tools.py) tools specifically for passive chip data analysis.
- [active_tools.py](./active_tools.py) tools specifically for active chip data analysis.

## Demo

The demo folder contains a simple example of how to use the library.

Current demos are:

- [hough_transform_peak_mapping.py](./demo/hough_transform_peak_mapping.py)
- [passive_analyzer.py](./demo/passive_analyzer.py)

Read the [demo readme](./demo/readme.md) for more information.
