# Introduction

This is the developer guide for `RA-Core`. Aims to provide additional information on the data analysis background of the problem and share some Python tricks for new developers.

## Retrospective Analysis

`RA-Core` library is the core data analysis library in the `Retrospective Analysis` software bundle.

### CLI Version

The very first and simple version was a CLI script from March 2021, maybe from Michael Caverley and Eric Lyall (from 2015-2021). It was then maintained by [Samantha M. Grist](https://github.com/samanthagrist) until November 2021. See its [git history](https://github.com/SiEPIC/biosensors/commits/24538a2484b15e0f183e6f898d4421238fa2dcf0/RetrospectiveAnalysis/Retrospective_Analysis_Script.py).

### RA-GUI

The first GUI version of RA was developed by [Yifei Liu](https://github.com/EzekielDaun) in 2022 summer and maintained until August 2023. See [its code base as of 20230830](https://github.com/SiEPIC/biosensors/tree/f711a1501a7c1c2128a45eef7c6e91330f4c2fef/RetrospectiveAnalysis).

The abbreviation `RA` means this version.

Beginning in September 2023, [Piramon Tisapramotkul](https://github.com/piramonpan) will be the maintainer of `RA-GUI`.
