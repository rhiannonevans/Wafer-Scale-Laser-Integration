# Type Hint

Python [PEP 484](https://peps.python.org/pep-0484/)

Use [type hint](https://docs.python.org/3/library/typing.html) to improve code readability.

Type-annotated Python code should look similar to other static-type languages (C/C++, Java, C#, Rust, etc.).

## Visual Studio Code Support

`settings.json`

```json
    "python.analysis.typeCheckingMode": "basic"
```

Recommend to work with [Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens).
