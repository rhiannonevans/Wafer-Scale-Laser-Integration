# Equalization Process

## LTI Simulation

When running the simulation, the simulation time needs to be long enough to reach a steady state. The time to reach stable depends on the LTI property. See [sample code](https://drive.google.com/drive/folders/1wUNMpExYhLT4-xerHZTgqAq7uoDlNBt3?usp=drive_link).

Take one steady state period output as the converted wavelength for one input signal period.

## Interpolation

The converted wavelength will be unevenly spaced. Interpolate to mimic the passive wavelength format (evenly spaced).
